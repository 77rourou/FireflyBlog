同样一个大模型，有人用得得心应手，有人却觉得"人工智障"。差别往往不在模型，而在提示词。提示词工程（Prompt Engineering）就是通过设计输入文本来引导大模型稳定输出高质量结果的方法，是普通人最容易上手、性价比最高的 AI 技能。

## 一、什么是提示词

提示词（Prompt）是你发给大模型的整段输入，包括指令、背景、示例和期望的输出格式。大模型的本质是"根据输入预测下一个 token"，所以输入的质量直接决定输出的质量——提示词写得越好，回答就越接近你的预期。

## 二、核心原则

1. **清晰具体**：模糊的问题得到模糊的答案。"写个文案"不如"为一款面向大学生的咖啡产品写 50 字朋友圈文案，语气轻松"
2. **给足上下文**：说明背景、目标读者、限制条件，模型才知道该往哪个方向答
3. **指定输出格式**：要求用表格、列表、JSON 或 Markdown 输出，结果更整齐、更好用
4. **一次只做一件事**：任务拆得越细，效果越稳定
5. **迭代优化**：输出不满意时针对性地补充约束，而不是原样重试

## 三、结构化提示词模板

把提示词组织成固定结构，能大幅提升稳定性。推荐模板：

```text
# 角色
你是……

# 任务
请完成……

# 要求
- 要求 1
- 要求 2

# 输出格式
以 Markdown 表格输出，包含……

# 参考示例
输入：……
输出：……
```

实际例子：

```text
# 角色
你是一名资深 SEO 编辑。

# 任务
为文章《本地部署大模型》写 3 个标题候选。

# 要求
- 每个标题不超过 20 字
- 包含"本地"和"大模型"关键词
- 风格口语化

# 输出格式
编号列表，每个标题后附一句推荐理由。
```

## 四、进阶技巧

**角色扮演**：给模型设定专业身份，约束知识范围和口吻：

```text
你是拥有十年经验的 Python 工程师，请用通俗语言向我解释装饰器的原理，并给出一个实际例子。
```

**思维链（Chain-of-Thought）**：要求模型"逐步思考"再作答，能显著提升数学、逻辑类任务的准确率：

```text
请一步一步思考并写出过程：一个水池，甲管 3 小时注满，乙管 5 小时放空，两管同开几小时注满？
```

**少样本示例（Few-shot）**：给出 2~3 个输入输出对作为示范，让模型模仿格式与风格：

```text
将用户评价转为 1~5 星评分：
"物流太慢了" -> 2 星
"质量很好，下次还买" -> 5 星
"包装有点破损" -> ?
```

## 五、常见误区

| 误区 | 正确做法 |
| --- | --- |
| 提示词越详细越好，堆砌无关描述 | 只保留与任务相关的约束 |
| 一次问多个问题 | 拆分成多个独立请求 |
| 要求模型"绝对准确""绝不犯错" | 给出可验证步骤，必要时附参考答案 |
| 把隐私数据直接写进提示词 | 先脱敏，尤其调用云端 API 时 |
| 期待模型"理解潜台词" | 把要求明说，不要让对方猜 |

> [!TIP]
> 提示：提示词值得版本管理。把好用的模板存成文件（例如 `prompts/` 目录），需要时直接复用，长期积累就是你的"提示词资产"。

## 六、小结

提示词工程没有银弹，核心就四个字：**说清楚**。结合角色扮演、思维链、少样本等技巧并持续迭代，任何人都能让大模型的输出质量上一个台阶。想深入学习的可以阅读 [OpenAI 官方提示词工程指南](https://platform.openai.com/docs/guides/prompt-engineering)。
